# ShipIt Firebase Toolkit — feature overview

This brief overview describes the product at a marketing level. It does not disclose source code, implementation details, or complete technical documentation.

- **Player accounts:** connect common account and session needs to your Firebase project.
- **Game data:** support online player data and progression workflows.
- **Cloud capabilities:** bring selected Firebase services into a Unity project workflow.
- **Development workflow:** organize project-side configuration and work from within Unity.

You bring and operate the Firebase project. This overview does not list the supported service matrix or compatibility range; see the website and product documentation for current scope and requirements.
